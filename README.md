# Moya List

> 이게 뭐야? 하는 궁금증을 포착하고 해결 여부를 추적하는 학습 서비스

## 주요 기능
- 빠른 궁금증 등록
- 해결 여부 추적
- 태그/날짜/해결 여부별 필터링
- 검색 기능
- 학습 히트맵 및 통계
- 크롬 익스텐션으로 빠른 스크랩
- 게스트 모드 지원 

## 프로젝트 구조
```
moya-list/
├── backend/      # Spring Boot API 서버
├── frontend/     # React 웹 클라이언트
├── extension/    # Chrome Extension
└── docs/         # 설계 문서
```
