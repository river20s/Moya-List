# Moya List (모야 리스트)
Moya List는...
- **궁금증을 포착**하고 **해결 여부를 추적**할 수 있는 **학습 도구**입니다.
- [개인적으로 사용하던 공부법](https://github.com/river20s/TIL)을 발전시킨 것입니다.
- *내가 무엇을 모르는지 인지하고, **바로 그곳에서부터** 탐구를 시작합니다.*



### 주요 기능
- 아주 빠른 궁금증 등록
- 로그인을 안 해도 일단 등록 가능한 게스트 모드
- 궁금 해결 여부 추적
- 짧은 설명과 출처, 첨부파일 등 추가 가능
- 태그/날짜/해결 여부별 필터링
- 검색 기능
- 학습 히트맵
- 지난 일주일/한달/일년 단위로 나의 궁금증 카테고리 변화를 볼 수 있음
- 브라우저 익스텐션으로 빠른 스크랩


## 프로젝트 구조

moya-list/
